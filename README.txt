SARAH'S BIRTHDAY WEBSITE
========================

1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open the website in your browser.
4. On the page, tap "Play our melody" to start the original browser-generated tune.
5. Tap the gift, blow out the candles, and send hearts.

FILES
- index.html : page content
- style.css  : colors, layout, responsive design and animations
- script.js  : gift, petals, candle interaction, hearts and music

NOTES
- The music is an original little melody generated with the browser's Web Audio API.
  It does not need an MP3 file or an internet connection, but the browser may require
  a tap on the music button before it can play.
- Google Fonts are loaded online; if offline, the page uses fallback fonts.
- To personalize the Arabic letter, edit the paragraph with class="arabic" in index.html.
- You can add your photos by creating an image section or replacing the reason cards.
